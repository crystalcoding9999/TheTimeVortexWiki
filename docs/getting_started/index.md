# Getting Started

This section shows how to build a TARDIS and fly it.

You start with a junk TARDIS: a console with a hull you build round it.
Later you turn it into a police box that is bigger on the inside.

## The way there

Mine Zeiton-7 and cinnabar, and build machines that run on artron energy.
Make alloys and circuits, then a console and its modules.
Glue a hull round the console and fly it through the air and the time vortex.

The recipes on the wiki are the ones the mod uses.
